## 🎯 Test Environment Requirements

### Hardware
- [ ] Android device (Android 10/API 29 or newer)
- [ ] iOS device (iPhone 12 or newer recommended)
- [ ] Development workstation (Windows/macOS/Linux)

### Software Prerequisites
- [ ] Android Studio installed and configured
- [ ] ANDROID_HOME environment variable set
- [ ] Xcode (macOS only — not available on Windows)
- [ ] Node.js v20+ and npm
- [ ] Chrome browser (for Web Battery API testing)

### Project Setup
```bash
# 1. Verify Capacitor plugins
npm list @capacitor-community/battery-status @capacitor/screen-brightness

# 2. Sync native projects
npx cap sync

# 3. Build for testing
npm run build

# 4. Android build
cd android && ./gradlew assembleDebug

# 5. iOS build (macOS only)
npx cap open ios
```
