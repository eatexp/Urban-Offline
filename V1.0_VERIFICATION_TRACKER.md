### To Unblock Native Testing

```powershell
# 1. Install Android Studio from https://developer.android.com/studio
#    During setup: check "Android SDK" + "Android Virtual Device"

# 2. Set environment variables (run as Admin):
[Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LOCALAPPDATA\Android\Sdk", "User")
$path = [Environment]::GetEnvironmentVariable("Path","User")
[Environment]::SetEnvironmentVariable("Path", "$path;$env:LOCALAPPDATA\Android\Sdk\platform-tools;$env:LOCALAPPDATA\Android\Sdk\cmdline-tools\latest\bin", "User")

# 3. Restart terminal, then:
npm run build
npx cap sync android
cd android
.\gradlew assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```
