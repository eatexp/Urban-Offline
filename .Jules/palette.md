## 2026-05-08 - Progress Indicator Accessibility
**Learning:** SmartDownloadPrompt had visually styled progress bars, but lacked the necessary aria attributes to expose its progress to screen readers. Specifically, using `role="progressbar"` along with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` attributes makes the progress readable and announced to assistive technologies. I also added `role="region"` and an `aria-label` to the container modal, and `aria-pressed` to the model selection buttons to make the interactive elements more robustly accessible to keyboard and screen reader users.
**Action:** Always ensure progress indicators use native semantic HTML like `<progress>` or include `role="progressbar"` with appropriate valuenow attributes for accessible loading states. Modals that are visually disjointed should be explicitly labeled regions. Model selection buttons acting as toggles should use `aria-pressed`.
