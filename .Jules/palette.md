## 2024-05-14 - Accessible Mission Logs
**Learning:** While semantic `<button>` elements are great for clickable list items, be extremely careful not to nest interactive elements (e.g., placing a "Delete" `<button>` inside a row `<button>`). This creates invalid HTML and breaks screen reader navigation. Instead, if a list row needs its own distinct actions, keep the row as a `<div>` with `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler for keyboard events (Enter/Space). Icon-only buttons still require descriptive `aria-label`s.
**Action:** When implementing clickable list items that contain secondary actions (like delete buttons), use a `<div>` with `role="button"` and keyboard event handlers rather than a semantic `<button>` to avoid invalid nested interactive elements. Always verify icon-only buttons include `aria-label` attributes alongside `title` attributes.
